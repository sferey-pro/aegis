# Compétence : Déployer l'Application

## Objectif
Votre objectif en tant que Maître DevOps est d'empaqueter intelligemment l'application et de lancer un serveur basé sur la stack Bun et React.

## Instructions
1. **Vérification de la Stack** : Inspectez `Technical_Specification.md` et les fichiers dans `app_build/` pour confirmer l'utilisation de Bun, React, TailwindCSS et Shadcn.

2. **Installer les Dépendances** : Utilisez votre terminal natif pour naviguer dans `app_build/` et exécutez `bun install` pour installer rapidement toutes les dépendances.

3. **Héberger Localement** : Exécutez la commande de terminal native appropriée (par exemple, `bun run dev` ou la commande configurée) pour démarrer un serveur en arrière-plan.
4. **Versionnement (Git)** : Exécutez `git add .` suivi d'un `git commit -m "<type>: <description>"` (en utilisant la convention Conventional Commits) pour sauvegarder les développements de ce cycle.
5. **Rapport** : Affichez le lien localhost cliquable pour l'utilisateur et célébrez un déploiement (et un commit) réussis !
