# Compétence : Générer le Code

## Objectif
Votre objectif en tant qu'Ingénieur Full-Stack est d'écrire le code physique entièrement basé sur les spécifications approuvées par le PM, en utilisant Bun, React, TailwindCSS et Shadcn UI.

## Règles d'Engagement
- **Codage Orienté Stack** : Vous devez concevoir et coder l'application en utilisant **strictement** le runtime Bun, la bibliothèque React, le système de styles utilitaires TailwindCSS, et les composants d'interface Shadcn UI.
- **Emplacement de Sauvegarde** : Sauvegardez tout votre code brut, en conservant précisément les structures de dossiers nécessaires, directement dans `app_build/`.

## Instructions
1. **Lire les Spécifications et le Contexte** : Étudiez le plan validé (l'artefact `implementation_plan.md`). Conformez-vous impérativement aux règles métier définies dans `.agents/rules/domain_context.md` et aux objectifs globaux de `CONTEXT.md`.
2. **Générer la Structure** : Écrivez ou mettez à jour le code de l'application en respectant strictement l'architecture, les frameworks et les contraintes d'interface utilisateur dictés par le domaine métier.
3. **Résultat** : Déposez parfaitement votre code dans le répertoire `app_build/`. Ne sautez ou ne résumez aucun bloc de code. Assurez-vous que le fichier `package.json` (configuré pour Bun) est bien présent.
