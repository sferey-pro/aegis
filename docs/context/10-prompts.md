# 🤖 10. Bibliothèque de prompts IA

Table `prompts` : `title` (non vide, « Titre requis »), `body`, `tags`, `created_at`.

Listés par **`title` ASC**. Déduplication par titre à l'import : un titre existant est ignoré. Modification et suppression par id ; un id inexistant renvoie « Prompt introuvable » en 404.
